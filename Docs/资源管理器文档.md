# 资源管理器 (ResourceManager) 文档

## 1. 概述

资源管理器是 FokiGA 项目中的一个核心模块，负责统一管理游戏中的资源加载、卸载、归还和模板池功能。它提供了同步和异步加载资源的能力，并通过引用计数机制自动管理资源的生命周期，同时集成了模板池系统以提高对象复用效率。

## 2. 功能特性

### 2.1 核心功能

- **资源加载**：支持同步和异步加载各种 Unity 资源
- **资源管理**：通过引用计数自动管理资源生命周期
- **模板池**：提供对象复用机制，减少内存开销
- **线程安全**：支持多线程环境下的安全操作
- **错误处理**：完善的错误处理和日志记录

### 2.2 技术特点

- **单例模式**：全局唯一实例，方便访问
- **接口设计**：提供清晰的接口，易于扩展
- **性能优化**：通过模板池减少对象创建和销毁的开销
- **内存管理**：自动管理资源的加载和卸载，减少内存泄漏
- **兼容性**：支持 GameObject 和其他 Unity 对象类型

### 3.2 核心组件

- **IResourceManager**：资源管理接口，定义资源管理的核心功能
- **ITemplatePool**：模板池接口，定义模板池的核心功能
- **ResourceManager**：资源管理器实现，继承自 MonoBehaviour，实现了上述两个接口
- **ResourceInfo**：资源信息类，记录资源的使用情况和引用计数

## 4. 使用指南

### 4.1 初始化

1. 在场景中创建一个空 GameObject
2. 挂载 `ResourceManager` 组件
3. 该组件会自动以单例模式运行

### 4.2 资源加载

#### 4.2.1 同步加载

```csharp
// 加载预制体
var prefab = ResourceManager.Instance.Load<GameObject>("Character/unitychan");

// 加载材质
var material = ResourceManager.Instance.Load<Material>("Materials/Default");

// 加载纹理
var texture = ResourceManager.Instance.Load<Texture2D>("Textures/Logo");
```

#### 4.2.2 异步加载

```csharp
// 异步加载预制体
var prefab = await ResourceManager.Instance.LoadAsync<GameObject>("Character/unitychan");

// 异步加载材质
var material = await ResourceManager.Instance.LoadAsync<Material>("Materials/Default");
```

### 4.3 资源归还

```csharp
// 归还资源
ResourceManager.Instance.Return(prefab);
ResourceManager.Instance.Return(material);
```

### 4.4 模板池使用

#### 4.4.1 预热模板

```csharp
// 预热模板，创建3个实例
await ResourceManager.Instance.Preload<GameObject>("Character/unitychan", 3);
```

#### 4.4.2 获取模板实例

```csharp
// 从模板池获取实例
var instance1 = ResourceManager.Instance.Get<GameObject>("Character/unitychan");
var instance2 = ResourceManager.Instance.Get<GameObject>("Character/unitychan");
```

#### 4.4.3 归还模板实例

```csharp
// 归还实例到模板池
ResourceManager.Instance.Return(instance1);
ResourceManager.Instance.Return(instance2);
```

### 4.5 资源管理

```csharp
// 直接卸载资源
ResourceManager.Instance.Unload(prefab);

// 清空所有资源
ResourceManager.Instance.ClearAll();

// 获取当前加载的资源数量
int resourceCount = ResourceManager.Instance.GetResourceCount();
Debug.Log($"当前加载的资源数量: {resourceCount}");
```

## 5. API 参考

### 5.1 IResourceManager 接口

| 方法 | 描述 | 参数 | 返回值 |
|------|------|------|--------|
| `Load<T>(string path)` | 同步加载资源 | path: 资源路径 | T: 加载的资源 |
| `LoadAsync<T>(string path)` | 异步加载资源 | path: 资源路径 | Task<T>: 加载的资源 |
| `Return<T>(T resource)` | 归还资源 | resource: 要归还的资源 | void |
| `Unload<T>(T resource)` | 直接卸载资源 | resource: 要卸载的资源 | void |
| `ClearAll()` | 清空所有资源 | 无 | void |
| `GetResourceCount()` | 获取资源数量 | 无 | int: 资源数量 |

### 5.2 ITemplatePool 接口

| 方法 | 描述 | 参数 | 返回值 |
|------|------|------|--------|
| `Get<T>(string templateName)` | 获取模板实例 | templateName: 模板名称 | T: 模板实例 |
| `Return<T>(T instance)` | 归还模板实例 | instance: 要归还的实例 | void |
| `Preload<T>(string templateName, int count)` | 预热模板 | templateName: 模板名称<br>count: 预热数量 | Task |
| `Clear()` | 清空模板池 | 无 | void |

### 5.3 ResourceManager 类

#### 5.3.1 属性

| 属性 | 类型 | 描述 |
|------|------|------|
| `Instance` | ResourceManager | 单例实例 |

#### 5.3.2 方法

| 方法 | 描述 | 参数 | 返回值 |
|------|------|------|--------|
| `Awake()` | 初始化单例 | 无 | void |
| `OnAwake()` | 自定义初始化 | 无 | void |
| `OnDestroy()` | 销毁时清理资源 | 无 | void |

## 6. 最佳实践

### 6.1 资源路径管理

- 使用统一的资源路径命名规范
- 将常用资源路径定义为常量
- 避免硬编码资源路径

### 6.2 模板池使用

- 对频繁创建和销毁的对象使用模板池
- 合理设置预热数量，避免过度预热
- 及时归还不再使用的实例

### 6.3 内存管理

- 对于大型资源，使用异步加载
- 及时归还不再使用的资源
- 在场景切换时清空资源

### 6.4 性能优化

- 预热常用模板
- 批量加载资源
- 避免在 Update 中频繁加载资源

## 7. 常见问题

### 7.1 资源加载失败

**问题**：调用 `Load` 方法返回 null

**解决方案**：
- 检查资源路径是否正确
- 确保资源在 Resources 文件夹中
- 检查资源类型是否匹配

### 7.2 模板池实例状态异常

**问题**：从模板池获取的实例状态不正确

**解决方案**：
- 在归还实例前确保重置实例状态
- 检查实例是否被正确销毁

### 7.3 内存泄漏

**问题**：资源占用持续增加

**解决方案**：
- 确保所有资源都被正确归还
- 定期调用 `ClearAll()` 清理资源
- 检查是否有资源未被正确卸载

## 8. 扩展与定制

### 8.1 自定义资源加载策略

```csharp
public class CustomResourceManager : ResourceManager
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // 自定义初始化逻辑
    }
    
    public override T Load<T>(string path) where T : UnityEngine.Object
    {
        // 自定义加载逻辑
        return base.Load<T>(path);
    }
}
```

### 8.2 集成 Addressables

```csharp
public class AddressableResourceManager : ResourceManager
{
    public override async Task<T> LoadAsync<T>(string path) where T : UnityEngine.Object
    {
        // 使用 Addressables 加载资源
        var handle = Addressables.LoadAssetAsync<T>(path);
        await handle.Task;
        
        T resource = handle.Result;
        if (resource != null)
        {
            // 记录资源信息
            lock (_resourceLock)
            {
                string key = $"{typeof(T).Name}:{path}";
                _loadedResources[key] = new ResourceInfo
                {
                    Resource = resource,
                    ReferenceCount = 1,
                    IsAsync = true,
                    Handle = handle
                };
            }
        }
        
        return resource;
    }
}
```

## 10. 总结

资源管理器是 FokiGA 项目中一个重要的模块，它提供了统一的资源管理解决方案，包括资源加载、卸载、归还和模板池功能。通过合理使用资源管理器，可以有效提高游戏的性能和稳定性，减少内存泄漏的风险。
