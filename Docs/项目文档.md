# FokiGA 项目文档

## 1. 项目概述

FokiGA 是一个基于 Unity 引擎开发的游戏框架，采用 Actor-Component 架构模式，提供了一套完整的游戏开发解决方案。该框架旨在简化游戏开发流程，提高代码复用性和可维护性。

## 2. 项目结构

### 2.1 目录结构

```
Assets/
├── Scenes/              # Unity 场景文件
└── fokiga/              # 核心框架目录
    ├── Art/             # 美术资源
    ├── Input/           # 输入系统
    ├── Resources/       # 资源文件
    ├── Scenes/          # 游戏场景
    └── Scripts/         # 核心代码
        ├── Core/        # 核心基础类
        ├── GameMode/    # 游戏模式
        ├── GamePlay/    # 游戏玩法
        └── Message/     # 消息系统
```

### 2.2 核心模块

| 模块 | 描述 | 文件位置 |
|------|------|----------|

## 3. 核心架构

### 3.1 Actor-Component 系统

FokiGA 采用 Actor-Component 架构模式，类似于 Unity 的 GameObject-Component 系统，但提供了更灵活的扩展能力。

#### 3.1.1 ActorBase

`ActorBase` 是所有游戏实体的基类，负责管理组件集合和生命周期。

**主要功能：**
- 组件管理（添加、获取、移除）
- 事件广播
- 生命周期管理（Awake、Start、Update、Destroy 等）
- 真实对象管理（从预制体创建或附加到现有对象）

#### 3.1.2 ComponentBase

`ComponentBase` 是所有组件的基类，提供了标准化的生命周期方法和回调机制。

**主要功能：**
- 生命周期方法（Awake、Start、Update、Destroy 等）
- 回调系统（Update、FixedUpdate、LateUpdate）
- 事件监听
- 状态管理（激活/禁用）

### 3.2 事件系统

框架实现了一个灵活的事件系统，支持全局事件和局部事件。

**主要功能：**
- 事件注册与监听
- 事件广播
- 事件作用域（全局/局部）
- 线程安全

### 3.3 系统管理

`SystemBase` 提供了游戏系统的基础框架，用于管理游戏的各种子系统。

**主要功能：**
- 系统初始化与销毁
- 系统激活与禁用
- 系统更新（Update、FixedUpdate、LateUpdate）
- 优先级管理

## 4. 核心功能

### 4.1 角色系统

#### 4.1.1 CharacterActor

`CharacterActor` 是游戏角色的实现，继承自 `ActorBase`，管理角色的各种组件和行为。

**主要功能：**
- 角色初始化与配置
- 组件管理（相机、输入等）
- 角色状态管理

#### 4.1.2 CharacterManager

`CharacterManager` 负责管理游戏中的所有角色，采用单例模式。

**主要功能：**
- 角色创建与销毁
- 角色管理与查询
- 唯一ID生成

### 4.2 输入系统

`PlayerInputComponent` 实现了基于 Unity Input System 的输入处理。

**主要功能：**
- 输入事件注册与处理
- 移动输入管理
- 动作输入管理（跳跃、奔跑、滑行等）
- 输入状态缓存

### 4.3 相机系统

`CameraComponent` 实现了第三人称相机控制。

**主要功能：**
- 相机跟随目标
- 相机旋转控制
- 碰撞检测与 avoidance
- 平滑过渡效果

### 4.4 游戏模式

`TestGameModeLoop` 是游戏模式的示例实现，负责游戏的初始化和主循环。

**主要功能：**
- 游戏启动流程
- 角色生成与定位
- 游戏状态管理

## 5. 关键 API

### 5.1 Actor 相关

#### ActorBase.CreateFromPrefab
```csharp
public void CreateFromPrefab(GameObject prefab, Transform parent = null)
```
从预制体创建 Actor 实例。

#### ActorBase.AddComponent
```csharp
public T AddComponent<T>() where T : ComponentBase, new()
```
为 Actor 添加组件。

#### ActorBase.BroadcastEvent
```csharp
public void BroadcastEvent<TEvt>(TEvt eventData) where TEvt : EventDefinition
```
广播事件到所有监听器。

### 5.2 Component 相关

#### ComponentBase.AddUpdate
```csharp
public Guid AddUpdate(Action<float> updateFunction, int priority = 0, bool isOneShot = false)
```
添加 Update 回调。

#### ComponentBase.AddListener
```csharp
public void AddListener<TEvt>(Action<TEvt> listener) where TEvt : EventDefinition, new()
```
添加事件监听器。

### 5.3 Character 相关

#### CharacterManager.CreateCharacter
```csharp
public virtual CharacterActor CreateCharacter(GameObject characterPrefab, Transform parent = null, string actorId = null)
```
创建角色实例。

#### CharacterManager.GetAllCharacters
```csharp
public virtual List<CharacterActor> GetAllCharacters()
```
获取所有角色实例。

## 6. 技术特点

### 6.1 架构优势

- **模块化设计**：采用 Actor-Component 架构，实现了高度模块化
- **事件驱动**：基于事件系统的通信机制，降低组件间耦合
- **生命周期管理**：标准化的生命周期方法，便于统一管理
- **线程安全**：关键操作采用锁机制，确保线程安全

### 6.2 性能优化

- **回调系统**：采用优先级排序和缓存机制，提高回调执行效率
- **内存管理**：合理的对象创建和销毁，减少内存泄漏
- **碰撞检测**：相机系统实现了高效的碰撞检测

## 7. 使用指南

### 7.1 创建角色

```csharp
// 从预制体创建角色
GameObject characterPrefab = Resources.Load<GameObject>("Character/unitychan");
CharacterActor character = CharacterManager.Instance.CreateCharacter(characterPrefab, parentTransform);
character.RealObject.transform.position = spawnPosition;
character.Activate();
```

### 7.2 添加组件

```csharp
// 为角色添加相机组件
CameraComponent cameraComponent = character.AddComponent<CameraComponent>();

// 为角色添加输入组件
PlayerInputComponent inputComponent = character.AddComponent<PlayerInputComponent>();
```

```csharp
private void OnMoveInputChanged(InputEvents.MoveInputChangedEvent evt)
{
    // 处理移动逻辑
}
```

```csharp

    // 实现其他生命周期方法
```

## 10. 总结

FokiGA 是一个功能完善、架构清晰的游戏框架，为 Unity 游戏开发提供了一套标准化的解决方案。通过 Actor-Component 架构、事件系统和系统管理，实现了高度模块化和可扩展的游戏开发环境。框架不仅提供了基础的游戏功能，还为开发者预留了充分的扩展空间，适合各类游戏项目的开发需求。
